Not just a higher R².
A defensible result.

A Jupyter Notebook exploring a regression problem using sales data. The goal is to find a strong R² score while examining how meaningful and reliable the result is.

Rather than treating a metric as the whole story, the notebook explains why particular code and machine-learning approaches were chosen, making the reasoning behind the analysis part of the project.

Mnemo - Independent app

Learning technology / functional prototype
02 - Mnemo / v1.0.1

Encode. Connect. Recall.

Mnemo is a cross-platform mnemonic learning application designed to make it easier to turn abstract information into personal mental associations.

The current prototype includes editable Symbol Lists, optional AI-assisted mnemonic word suggestions and a locally operated Major System. Users can review, customise and maintain their own associations rather than relying on AI-generated content.

My aim is to combine learning research with practical software development, while keeping the learner in control.

Research-informed concept. Mnemo's effectiveness as an integrated learning system has not yet been established through controlled empirical evaluation.
View Mnemo on GitHub ↗
Project at a glance
  • StatusFunctional development prototype, v1.0.1
  • Implemented15 predefined Symbol Lists with 647 available learning positions, not 647 completed associations
  • AI supportOptional mnemonic suggestions with manual editing and user control
  • Core systemLocal Major System with configurable phonetic assignments
  • Tech stackReact Native, Expo, TypeScript, Node.js, Express and OpenAI API
  • Next stepsTraining and Dreamscapes modes, scientific study design and further testing
